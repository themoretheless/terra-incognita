# Архитектура

Приложение собирается Vite. Интерфейс — на движке Svet (сигналы на Rust/WASM, JSX без
виртуального DOM) и языке разметки Forma (`.ui`); оба приходят из подмодуля `vendor/forma`
(пакет `packages/svet`, в `package.json` — `svet-engine`). Карта, canvas пелены и хранилище —
обычные модули без фреймворка. Leaflet подключается UMD-скриптом с SRI, MapLibre и h3-js
подгружаются по требованию.

```
index.html ── src/main.js (оркестратор, window.terra)
               ├─ fog-store.js        хранилище открытого (источник правды)
               │   ├─ db.js           IndexedDB: схема, миграции, ошибки
               │   └─ codec.js        RLE, base64, fnv1a, popcount
               ├─ tracks.js           треки по дням, GPX/KML/GeoJSON
               ├─ markers.js          флажки и фото-заметки, DOM-маркеры
               ├─ gps.js              watchPosition, фильтры, Wake Lock
               ├─ game.js             опыт, достижения, квесты, покрытие
               ├─ osm.js              Overpass: места, границы, улицы (кэш 7 дней)
               ├─ map/leaflet-view.js растровая подложка
               ├─ map/maplibre-view.js векторная подложка + vector-styles.js
               ├─ render/fog-renderer.js пелена, режимы, overlay, compose
               │   └─ render/raster-worker.js битовая карта → ImageBitmap
               └─ ui/
                   ├─ model.ts        модель представления: сигналы Svet
                   ├─ App.tsx         оболочка страницы (Svet JSX)
                   ├─ panels.tsx      окна: настройки, данные, хроника, шаринг, метки
                   ├─ dialog.tsx, toast.ts, forma.ts
                   ├─ minimap.js
                   └─ views/*.ui      Forma: меню, стили, сводка, статистика,
                                      журнал, справка, знакомство
```

## Интерфейс: кто что делает

- **`model.ts`** — единственное место, где живёт состояние интерфейса: набор сигналов
  (`ui.progressShown`, `ui.pois`, `ui.toasts`…). `main.js` только пишет в них, DOM не трогает.
- **Forma `.ui`** — декларативные области. Сигналы модели передаются как `viewModel`
  и доступны в разметке по имени; клики возвращаются событиями (`clicked -> events.open('stats')`).
  У каждого компонента свой блок `i18n ru/en`, язык переключает сигнал `ui.locale`.
  Свойства, которых Forma не знает (`part`, `panel`, `pressed`, `found`), попадают в
  `data-*`-атрибуты: по ним работают стили (`[data-part='poi'][data-found='true']`) и тесты.
- **Svet JSX** — оболочка страницы (семантические теги, ориентиры и ARIA), модальные окна
  на `<dialog>` и формы с `select`, ползунками, флажками и файлами: таких контролов
  в Forma поверх Svet пока нет. Реактивные выражения записаны явными стрелками.
- **Императивные узлы** — `#map`, оба canvas, слой маркеров и мини-карта создаются в `App.tsx`,
  а управляют ими Leaflet/MapLibre, `FogRenderer`, `MarkerLayer`, `Minimap`.

Ограничения Forma, которые стоит помнить при правке `.ui`: свойства элемента пишутся до
вложенных элементов; строка цикла `for` должна иметь один корневой элемент; в строках нельзя
`->` и `<->`; значения `i18n` не содержат `;`.

## Поток данных

1. Позиция (GPS или клавиши) → `main.movePlayer` → `fog.reveal` / `revealPath`.
2. `FogStore` помечает клетки, обновляет индекс и агрегаты, планирует запись
   и шлёт событие `reveal`.
3. `FogRenderer.requestDraw()` ставит один кадр в rAF. Кадр берёт
   `chunksInBounds(view)`, для каждого чанка — маску уровня детализации
   (32–256 px по экранному размеру), из кэша или из воркера.
   На мелких масштабах (чанк меньше 160 px) маски склеиваются в мозаики
   16×16 чанков (тайл z10), которые пересобираются только при смене версии
   своих чанков. Масштабирование масок — билинейное (`imageSmoothingQuality =
   'low'`): бикубическое в Chromium стоило 5–14 мс на кадр.
4. После каждого изменения `main.js` обновляет сигналы в `ui/model.ts`; Svet точечно
   меняет привязанные узлы. Панели читают `app.fog`, `app.game`, `app.tracks`.

## Подложка

Обе реализации (`LeafletView`, `MapLibreView`) дают один интерфейс:
`project`, `getBounds`, `getZoom`, `setView`, `metersToPixels`, `drawBasemap`,
события `move`/`zoom`/`click`. Векторная включается в настройках; при ошибке
загрузки остаётся растровая.

## Отклонения от плана

- Мягкий край — билинейное покрытие уменьшенных масок, а не настоящее поле расстояний.
- Red Alert «отрастает» по чанку целиком: время посещения хранится на чанк.
- GeoJSON-контуры трассируются по чанкам, соседние чанки не сливаются.
- Воркер растеризует маски; компоновка кадра — в основном потоке.
- Импорт H3 растрирует ячейки и потому неточен на краях.
