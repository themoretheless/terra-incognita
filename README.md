# Terra Incognita

Небольшая интерактивная карта экспедиции с туманом войны. Карта использует
онлайн-тайлы OpenStreetMap через Leaflet: двигайтесь мышью, стрелками или
`WASD`, и исследованная область будет открываться вокруг путешественника
в радиусе 30 метров.

Для запуска достаточно открыть `index.html` в браузере с доступом в интернет.
## Хранение открытых областей

Открытое не сбрасывается между сессиями. Мир нарезан на клетки тайловой сетки
Web Mercator (зум 22, в Париже около 6 м), клетки группируются в чанки 256×256
(тайлы зума 14) и хранятся битовыми картами по 8 КБ в IndexedDB (запасной
вариант — `localStorage`). Запись отложенная, принудительно выполняется при
уходе со страницы. Позиция путешественника и найденные объекты тоже
сохраняются. В подвале есть экспорт и импорт JSON и полный сброс.
Реализация — `fog-store.js`.

Кнопка «Экспорт H3» выгружает открытое как набор ячеек H3 (Uber) разрешения 12,
сжатый `compactCells`. Библиотека h3-js подгружается только при нажатии.
