# Terra Incognita

Небольшая интерактивная карта экспедиции с туманом войны. Карта использует
онлайн-тайлы OpenStreetMap через Leaflet: двигайтесь мышью, стрелками или
`WASD`, и исследованная область будет открываться вокруг путешественника
в радиусе 30 метров.

Для запуска достаточно открыть `index.html` в браузере с доступом в интернет.
